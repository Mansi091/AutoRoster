# Project history

This repository retains older CLI and pipeline code for reference. The active supervisor web application is the FastAPI service in backend/app, launched by app.py, and the React/Vite client in frontend.

The legacy/ directory is an archived copy of an earlier implementation. It may use older settings and data formats; new web-app features should be implemented in backend/app and frontend.

Runtime employee data, exports, caches, and local credentials are intentionally excluded from the repository. See the root README for setup instructions.
